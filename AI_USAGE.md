# AI Usage Disclosure

This project used AI tools as assistance during development.

## AI-assisted activities
- Understanding the research paper and its methodology.
- Debugging and explaining implementation issues.
- Assistance with code organization and documentation.
- Interpreting experimental results and preparing visualizations.

## Human contributions
- Reviewing and validating the implementation.
- Running experiments and collecting results.
- Checking model outputs and evaluation metrics.
- Making final decisions about the methodology and reported findings.

## Verification
AI-generated suggestions and code were reviewed and tested by the project team.
Experimental results reported in this repository come from actual model executions.
